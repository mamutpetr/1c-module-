Реквізити для 1С

IBAN, ЄДРПОУ та РНОКПП перевіряються за контрольною сумою
Тут з'являться IBAN, коди, дати й сума до сплати.

Рушій: Tesseract 5 (WebAssembly, tesseract.js 7), моделі best_int. PDF розгортається через pdf.js при 300 dpi, TIFF (LZW, Deflate, JPEG, CCITT G3/G4) через UTIF.js. Перший запуск завантажує ~9 МБ. Для пакетної обробки на сервері є ocr-test/ocr.py у репозиторії.
