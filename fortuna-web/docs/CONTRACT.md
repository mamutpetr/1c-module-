# Формат даних ФОРТУНА (`fortuna-data`, версія 1)

Один JSON-документ, який сторінка отримує трьома способами:

| Джерело | Звідки | `source` |
|---|---|---|
| HTTP-сервіс розширення | `GET <база>/hs/fortuna/data` | `bas-http` |
| Експорт з обробки | кнопка «Для телефона» у формі EPF, файл `fortuna-data.json` | `bas-export` |
| Демо | вбудований у сторінку набір | `demo` |

BAS віддає **сирі дані**, які вже залежать від бази: склад рецептур, ціну останньої закупівлі для кожної пари матеріал+характеристика (функції `ПолучитьПоследниеЦеныЗакупки` + `НайтиПоследнююЦену`), ціну останньої продажі з розрахованим ПДВ і вагою ящика (`ПолучитьПоследниеЦеныПродаж` + `ИзвлечьВесЯщикаКг`), статуси, категорії, історію.
Усю арифметику (собівартість грн/кг, націнка, маржа, проблеми, сценарії) рахує сторінка (`src/core.js`) за тими самими правилами, що й форма v5.0.

Усі ідентифікатори — `УникальныйИдентификатор()` посилань у нижньому регістрі (`"8f1c…"`). Дати — локальний час сервера BAS у форматі ISO без поясу (`"2026-10-14T09:30:00"`), як їх пише `ЗаписатьJSON`.

```jsonc
{
  "format": "fortuna-data",
  "version": 1,
  "source": "bas-http",                       // bas-http | bas-export | demo
  "generatedAt": "2026-10-14T09:30:00",       // ТекущаяДата() на сервері
  "base": "Виробництво (робоча)",             // необов'язково: назва бази
  "user": "Бухгалтер",                        // необов'язково: ИмяПользователя()
  "methodology": {
    "batchKg": 1000,                          // рецептури складені на 1000 кг
    "processingPerTon": 50000,                // переробка, грн/т, додається один раз
    "historyTag": "v3.3 грн/кг; переробка 50000 грн/т"
  },
  "features": {                               // що є в конфігурації
    "statusAttribute": true,                  // Спецификации.СтатусРецептуры
    "categoryAttribute": true,                // Спецификации.КатегорияКалькуляции
    "historyRegister": true,                  // РегистрСведений.ИсторияКалькуляций
    "materialHistoryRegister": true,          // РегистрСведений.ИсторияЦенМатериалов
    "writes": true                            // сервіс приймає зміни категорій/статусів
  },
  "messages": [                               // діагностика, як Сообщить() у формі
    "РЕЦЕПТУРИ: таблична частина = Состав; матеріал = Номенклатура; кількість = Количество; рядків = 4210"
  ],

  "products":        { "<uuid>": "Вареники з картоплею 900 г" },
  "materials":       { "<uuid>": "Борошно пшеничне в/г" },
  "characteristics": { "<uuid>": "9%" },

  "specs": [                                  // усі непомічені на видалення специфікації
    {
      "id": "<uuid>",
      "name": "Вареники картопля v3",         // Строка(Спецификация)
      "product": "<uuid>",                    // Спецификация.Владелец
      "status": "Нова",                       // СтатусРецептуры як рядок, "" якщо реквізиту немає
      "category": "UA_RUD"                    // КатегорияКалькуляции (СокрЛП), "" якщо немає
    }
  ],

  "rows": [                                   // склад: рядки ТЧ у порядку запиту (Товар, Спецификация, НомерСтроки)
    {
      "spec": "<uuid>",
      "material": "<uuid>",
      "char": "<uuid>",                       // null, якщо характеристика порожня
      "unit": "кг",                           // БезопаснаяСтрока(ЕдиницаИзмерения)
      "qty": 412.5                            // кількість на 1000 кг готової продукції
    }
  ],

  "purchasePrices": {                         // НайтиПоследнююЦену(материал, характеристика)
    "<materialUuid>|<charUuid>": {            // для порожньої характеристики: "<materialUuid>|"
      "exVat": 16.25,                         // ЦенаБезНДС
      "withVat": 19.5,                        // ЦенаСПДВ
      "date": "2026-09-02T00:00:00",          // Период (дата прихідної)
      "doc": "Прихідна накладна 00-000731 від 02.09.2026",
      "currency": "грн"                       // Строка(Валюта); сторінка сама перевіряє ЭтоГривнаИлиПусто
    }
  },                                          // ключа немає = ціну не знайдено

  "sales": {                                  // ПолучитьПоследниеЦеныПродаж(), ключ = товар
    "<productUuid>": {
      "status": "OK",                         // або "ПЕРЕВІР ПДВ У РОЗХІДНІЙ", "ЦІНА В ІНШІЙ ВАЛЮТІ: EUR", ...
      "exVat": 612.0,                         // грн за одиницю продажу (ящик) без ПДВ
      "withVat": 734.4,
      "unit": "ящ (4,5 кг)",                  // ЕдиницаПродажи
      "boxKg": 4.5,                           // ИзвлечьВесЯщикаКг(); 0 = вагу не визначено
      "date": "2026-10-10T14:05:00",
      "doc": "Видаткова накладна 00-001204 від 10.10.2026"
    }
  },

  "history": {                                // ЗагрузитьИсториюКалькуляций(): [поточний, попередній]
    "<specUuid>": [
      { "period": "2026-10-01T08:00:00", "cost": 98.12, "sale": 136.0, "markup": 38.61, "materials": 9, "pricesFound": 9 },
      { "period": "2026-09-01T08:00:00", "cost": 95.4,  "sale": 136.0, "markup": 42.56, "materials": 9, "pricesFound": 9 }
    ]
  },

  "serverCalc": {                             // необов'язково (тільки HTTP-сервіс): розрахунок BAS для звірки
    "<specUuid>": { "materials": 9, "pricesFound": 9, "cost": 98.1234, "sale": 136.0, "markup": 38.6 }
  }
}
```

## Правила

- Кожен `rows[].spec` є в `specs`. Рядки без матеріалу або з нульовою кількістю сервер не надсилає (як запит у `ПрочитатьТабличнуюЧастьСпецификаций`).
- Рецептура потрапляє в каталог, лише якщо має хоча б один рядок складу.
- Ціна закупівлі вважається знайденою для собівартості, якщо ключ є і валюта гривнева або порожня (`ЭтоГривнаИлиПусто`). Для аналітики (вплив, план, конструктор) потрібна ще й `exVat > 0`, як в `UX42_ОбновитьПослеЗагрузки`.
- `history` містить лише записи з `Комментарий = methodology.historyTag`, не більше двох на рецептуру, новий першим.
- Невідомі поля сторінка ігнорує. Нові поля додаються без зміни `version`; несумісні зміни підвищують `version`.

## Запити HTTP-сервісу (`/hs/fortuna`)

| Метод і шлях | Тіло | Відповідь |
|---|---|---|
| `GET /ping` | | `{"ok":true,"user":"…","version":1}` |
| `GET /app` | | сама сторінка (HTML) |
| `GET /data` | | документ вище |
| `GET /spec/{id}/prev` | | `{"spec":"…","prices":{"<mat>|<char>":12.5}}` — ціни матеріалів з попереднього знімка (`ПолучитьПредыдущиеМатериалыИзРегистра`) |
| `POST /spec/{id}/category` | `{"code":"UA_RUD"}` або `{"code":"NONE"}` | `{"ok":true,"message":"ГОТОВО: … → Україна / Рудь"}` |
| `POST /spec/{id}/status` | `{"status":"Нова"}` або `{"status":"Стара"}` | `{"ok":true,"message":"ГОТОВО: … -> Стара"}` |
| `POST /snapshot` | `{}` | `{"ok":true,"message":"СПІЛЬНА ІСТОРІЯ: записано рецептів 3, рядків матеріалів 41."}` |

Помилки: HTTP 400/404/409/500 з тілом `{"ok":false,"error":"ПОМИЛКА: …"}`.
Коди категорій: `UA_RUD`, `UA_SILPO`, `UA_METRO`, `UA_FEDYK`, `UA_OP`, `UA_MIDAS`, `EX_DOVGAN`, `EX_ITALY`, `EX_ROMANIA`, `EX_GEYA`, `EX_CZECH`, `EX_ISRAEL`, `NONE`.
